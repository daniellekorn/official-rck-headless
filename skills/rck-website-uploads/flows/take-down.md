# Flow — taking something down

First work out **what kind of thing it is** — a flyer, a Torah sheet, or a past event. It changes what "take down" can even mean.

Then find the row, **read its title back**, and confirm you have the right one before touching anything.

Either way this is an update or a delete on an existing row: read `reference/wix.md` before you write.

## A flyer can be hidden

Set `removeAfter` to yesterday: off the site immediately, and back again by changing the date. The row is untouched otherwise.

Offer this rather than deleting, and say it's reversible. Delete only if they ask a second time.

## A Torah sheet can't

There's no hide or expiry field on `TorahSheets`. Taking one down means **deleting the row**, and it can't be un-hidden — only re-uploaded. Say that plainly and get an explicit yes.

The PDF itself stays in the Media Manager, so a re-upload wouldn't start from nothing. Mention that — it's the part that makes the decision easier.

## Read-back

Same as everywhere else: a block with what's about to happen, then "Go ahead?" For a hide, say what's being preserved.

```
Flyer:    Shavuos Night Learning
Doing:    hiding it — comes off the site now
Staying:  everything else; say the word and it's back
```

For a delete, be explicit that it isn't reversible:

```
Sheet:    Eikev (Torah Bytes, תשפ״ו)
Doing:    deleting the row — this can't be undone
Staying:  the PDF stays in the Media Manager, so it can be re-uploaded
```

## Verify

Load the page and confirm the thing is gone. For a hidden flyer, confirm the rest of its section still looks right.
